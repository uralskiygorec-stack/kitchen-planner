# Публикация конструктора кухни

Это собранная версия существующего kitchen-project, без отдельного движка или копии проекта пользователя. dist/index.html содержит проверенную статическую сборку. review.html — текстовый обзор для просмотра инструментами без JavaScript; interface.png — снимок контрольного примера, а не сохранённая кухня посетителя. Обновлять сборку из ../dist/index.html; исходники остаются в родительском проекте и shared-furniture.
